# GikaiLens
**A RAG-based research assistant for exploring historical Japanese parliamentary debates (1890–1947)**

GikaiLens is a capstone project for the course *GenAI for Humanists* at the University of Vienna.

The aim is to develop a research assistant that uses retrieval-augmented generation (RAG) to help researchers explore historical Japanese parliamentary debates.

The planned features include searching for relevant speeches, generating source-based summaries, comparing different speakers' arguments, and translating historical Japanese texts. If time permits, I would also like to explore the integration of academic literature into the analysis.

The project will use parliamentary proceedings made available through the National Diet Library of Japan.
